# Kasi Pangan — Smart Agriculture Dashboard

Struktur:
- index.html  -> struktur halaman/dashboard
- style.css   -> seluruh desain, warna, layout, responsive
- script.js   -> interaksi tombol, menu, import file, dan logout

Cara menjalankan:
1. Ekstrak folder.
2. Buka index.html di browser.
3. Tidak membutuhkan server untuk tampilan dasar.

Catatan:
- Hero menggunakan gambar dari URL Unsplash agar tampil mirip referensi.
- Untuk aplikasi produksi, ganti URL gambar dengan asset lokal.
- Ikon saat ini menggunakan simbol Unicode supaya project langsung berjalan tanpa library tambahan.
